## 解决的问题

AI 板块投资有四大痛点：

| 痛点 | 本 Skill 的解法 |
|------|----------------|
| 赛道太多，不知道怎么分类 | 14+ 细分赛道，按上游/中游/下游三层分组 |
| 每天看盘太累，信息散落各处 | 一键生成 PDF 报告，8 个模块覆盖估值/资金/资讯/建议 |
| 不知道该买 ETF 还是主动型基金 | 动态发现基金，按板块区分 ETF 和主动型，新基金标 `[新上]` |
| 报告都是马后炮，缺乏前瞻 | 四维信号矩阵 + 反共识校准 + 大跌加仓分析 + 止盈后加回条件 |

---

## 核心亮点

- **四维信号矩阵**：不再单一看 PE 止盈，每层 4 个维度（估值/盈利/供给竞争/情绪）综合打分
  - 上游：PE + EPS增速 + 供给紧张度 + 情绪偏离（核心：结构性短缺）
  - 中游：PE + 增长(API/用户) + 竞争格局 + 情绪偏离（核心：变现能力）
  - 下游：PE + 渗透率 + 产业趋势/政策 + 情绪偏离（核心：渗透率拐点）
- **反共识校准**：恐惧贪婪偏离近20日均值>15点触发，结合基本面判断是"错杀"还是"真恶化"
- **大跌加仓分析**：赛道跌>3%自动触发四步判断（查原因→查隔夜→查期货→下判断）
- **止盈后加回条件**：每条止盈建议附带具体加回阈值
- **纯动态基金发现**：不依赖固定基线，每次运行从搜索结果实时提取
- **5次搜索覆盖全链**：市场行情 + 上游基本面 + 中下游基本面 + 基金业绩 + 情绪隔夜
- **数据驱动模板**：HTML 完全由 JSON 驱动，赛道/基金增删无需改代码
- **首选 Playwright 渲染**：效果最佳；无法使用时降级 WeasyPrint，两个模板输出一致

## 使用方式

### 前置要求

**首选 — Playwright**（效果最佳）：

```bash
pip install playwright --break-system-packages
python -m playwright install chromium
python -m playwright install-deps chromium
```

**降级 — WeasyPrint**（纯 Python 无需浏览器）：
```bash
pip install weasyprint --break-system-packages
```

> 两个脚本都接收 Step 2 生成的同一个动态 HTML 文件，不需要手动切换模板。

### 在 TRAE SOLO 中使用

1. 将 `ai-sector-investor-skill` 文件夹放入 SOLO 的 skills 目录
2. 在对话中输入：「生成今天的 AI 板块投资报告」
3. SOLO 自动执行：5 次搜索 → 四维信号计分 → 反共识校准 → 动态发现基金 → 生成 HTML → 渲染 PDF
4. 在工作目录找到 `AI板块投资报告.pdf`

### 作为定时任务

配合 SOLO 的 Schedule 工具，可设置每日 18:00 盘后自动生成推送。

## 技术架构

```
数据获取(WebSearch x5)
  → 搜索1: 市场行情（PE/涨跌/北向）
  → 搜索2: 上游基本面（产能/EPS/技术突破）
  → 搜索3: 中下游基本面（API/渗透率/政策）
  → 搜索4: 基金业绩排名
  → 搜索5: 情绪+隔夜（美股/期货/反弹）
     ↓
大跌加仓分析(Step 1.6)
  → 跌>3%触发：查原因→查隔夜→查期货→下判断
     ↓
四维信号计分(Step 1.7)
  → 每层4维度打分：[多X空Y]
  → 上游特殊：结构性短缺减半止盈
     ↓
反共识校准(Step 1.8)
  → 恐惧贪婪偏离>15点 + 基本面验证
     ↓
基金动态发现与分层(Step 1.5)
  → 按关键词分层（上游/中游/下游）
  → Top基金持仓验证
  → 同层级按业绩排序
     ↓
组装 JSON 数据
     ↓
注入 HTML 模板(DATA 对象)
     ↓
首选 Playwright → PDF（降级 WeasyPrint）
```
